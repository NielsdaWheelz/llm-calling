# Live Evidence

Evidence qualifies only the code revision and external boundary that produced
it. Codex records dated through 2026-09-08 predate the shared WebSocket/Unix
socket boundary and remain historical records; they do not qualify the current
runtime. Run the current opt-in live gates to produce current Codex evidence.

Current evidence does not synthesize a native version from a package constant.
Record actual installed CLI and running-server observations separately during
qualification; they may differ after an install that leaves a healthy service
running. Neither observation is runtime admission authority.
